# NA-Wink

Prototype controller for MX-5 pop-up headlights: ESP32 firmware, hardware
design, and companion app.

- `firmware/` — controller, BLE protocol, and host model.
- `hardware/` — harness, pinout, KiCad design, and circuit notes.
- `simulator/` — motor-free behavioral simulation.

Prototype only. Vehicle pinout, wiring, and hardware behavior still need
bench and donor-car validation; see `hardware/kicad/README.md`.
